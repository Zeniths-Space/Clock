# Roadmap

1. Interface for all five tabs (done, this version).
2. Alarms: saved alarms, the add/edit sheet in the Elara form design, exact alarms with
   `AlarmManager.setAlarmClock`, a full-screen ringing screen, snooze, sound and vibration choice,
   reboot and time-zone change handling.
3. Timer alerts and a notification while a timer runs; several timers.
4. World clock: search and add cities, reorder and remove them.
5. Settings: home city, 12h/24h, week start, sounds.
